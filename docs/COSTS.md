# Cost and quota plan

Provider facts below were checked against official pages on 2026-10-20 and must be rechecked at deployment. One Supabase test project is running; no Vercel project or paid resource has been created by this work. The test project's actual billing state should be checked in its owner's dashboard; future free-tier eligibility and monthly cost are not guaranteed.

| Resource                                                                                 | Current published free allowance / limitation                                                                                    | Planned use and upgrade trigger                                                                                        |
| ---------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| [Supabase Free](https://supabase.com/docs/guides/platform/billing-on-supabase)           | 2 free projects; 500 MB database, 1 GB storage, 5 GB egress, 50,000 MAU, 2 million Realtime messages/month, 200 peak connections | one project for pilot; monitor DB size, egress, connections and messages; upgrade or reduce use as thresholds approach |
| [Supabase production guide](https://supabase.com/docs/guides/deployment/going-into-prod) | free project may pause after about 7 days of low activity; downloadable managed backups unavailable                              | define external backup/restore plan before real user data; reconsider plan if continuity is needed                     |
| [Supabase Auth SMTP](https://supabase.com/docs/guides/auth/auth-smtp)                    | built-in sender is for testing and limits recipients/rates                                                                       | production signups require a verified SMTP service with its own quotas/costs; provider not yet selected                |
| [Vercel Hobby](https://vercel.com/docs/plans/hobby)                                      | $0 personal non-commercial plan; usage caps include 1 million function invocations and 4 active CPU hours                        | verify non-commercial eligibility; track usage, build volume and functions; higher plan may be necessary               |
| Web Push                                                                                 | browser push API has no app-side provider subscription in this design                                                            | Vercel execution and outbound traffic count toward provider usage; monitor delivery failures                           |
| Custom domain                                                                            | not planned                                                                                                                      | use confirmed free Vercel subdomain; no purchase                                                                       |

The pilot estimate of 1,000 registrations/100 busy-day users fits several published headline quotas on paper, but simultaneous Realtime connections, image size, bandwidth, auth email volume and query costs are unmeasured. Free-tier exhaustion can pause service or prevent additional usage. Set alerts/periodic dashboard checks and record actual usage after pilot. Do not enable paid plans or usage-based charges without approval.
